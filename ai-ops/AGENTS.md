# AI-OPS 范围指令（仅作用于 ai-ops/ 子目录）

这是公开仓库中的**文档交接试验**，不是生产开发、交易系统或API令牌管理项目。

- 默认READ_ONLY；用户授权的小测试只改本分支的 `ai-ops/` 文件。
- 先读 README.md、STATUS_20261028.md、指定任务。新电脑若无法写回原仓库，个人fork/本地patch即可；禁止索取主GPT、主Codex账号凭据。
- **主GPT/主Codex/宝宝GPT/宝宝Codex** 是角色标签，不代表具备跨账号远程调用权。不能声称已联系或已执行另一账号会话。
- 读取公开 `main` JSON必须记录实际trade_date、run_context、生成时间和文件SHA，禁止以main上最近文件推定今日实时。
- 只有在确认最新main内容后才能在文档中写“已核实”。失败标NEEDS_RECHECK，不补造证明。
- 不修改本分支之外的文件，不编辑 `latest_*.json`、`status.json`、`experiment*.json`、`recent_runs.json`，不操作腾讯云、MeoZ/TuShare、生产任务、真实账户、条件单。
- 严禁私有账号/持仓、券商截图、密钥、原始非公开策略或预测台账写入这个公开仓库。
- 结果回执必须区分：文件创建/更新成功、只读回查成功、实际宝宝Codex执行成功、用户人工审批状态。
